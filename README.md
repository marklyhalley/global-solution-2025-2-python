# Formulário de Iniciação e Quiz de Perfil Profissional




## 📌 Sobre o Projeto

Este projeto é um **Formulário de Iniciação** desenvolvido em
**Python**, que coleta informações básicas do usuário (nome, CPF e
e-mail) e realiza um **Quiz de Perfil Profissional** composto por 5
perguntas.

Com base nas respostas, o sistema classifica o usuário em um dos quatro
perfis: - Criativo e Comunicativo - Humano e Social - Analítico e
Estruturado - Técnico e Inovador

O sistema valida CPF e e-mail utilizando funções próprias, e ao final
grava todas as informações em um arquivo `forms.txt` para registro.

## 🧠 Funcionalidades Principais

### ✔️ Validação de CPF

-   Remove qualquer caractere que não seja número
-   Impede sequências repetidas
-   Calcula corretamente os dígitos verificadores

### ✔️ Validação de E-mail

-   Converte para minúsculas
-   Remove espaços internos
-   Verifica quantidade de caracteres, posição do @ e domínio

### ✔️ Quiz de Perfil

-   5 perguntas com alternativas de A a D
-   Aceita letras minúsculas e maiúsculas
-   Sistema de desempate com pesos
-   Identifica e exibe o perfil dominante

### ✔️ Registro de Informações

Informações gravadas em `forms.txt` automaticamente.

## ▶️ Como Executar

1. **Acesse o repositório no GitHub:**
   [https://github.com/marklyhalley/global-solution-2025-2-python](https://github.com/marklyhalley/global-solution-2025-2-python)

2. **Baixe o projeto** de uma das seguintes formas:

   **Opção A – Clonar o repositório com Git:**

   ```bash
   git clone https://github.com/marklyhalley/global-solution-2025-2-python.git
   ```

   **Opção B – Baixar como ZIP:**

   * Clique em **Code**
   * Escolha **Download ZIP**
   * Extraia o conteúdo no computador

3. **Acesse a pasta do projeto no seu computador:**

   ```bash
   cd global-solution-2025-2-python
   ```

4. **Execute o arquivo principal do programa:**

   ```bash
   python main.py
   ```

   *(ou `python3 main.py` dependendo do sistema)*

5. **Siga as instruções exibidas no terminal**, preenchendo:

   * Nome
   * CPF
   * E-mail
   * Respostas do quiz de perfil

6. Após a conclusão, será criado ou atualizado o arquivo:
   **forms.txt**
   contendo o registro completo da inscrição.
